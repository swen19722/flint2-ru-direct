# Happ Tunnel — RU Direct / VPN for foreign services

Обновляемые правила для **Happ Tunnel (Windows и Android)** из **того же источника**, что и Flint 2:
`../ru-direct-extended.domains.txt` и `../ru-direct-v2raya.rules.txt`.

## Установка на другом компьютере

1. Установите Happ и добавьте собственный VLESS-сервер/подписку. **В GitHub личные ключи и VLESS-ссылки не публикуются.**
2. Откройте **[Happ_Import_Link.txt](Happ_Import_Link.txt)** и скопируйте **всю одну строку**, начинающуюся с `happ://routing/onadd/`.
3. Импортируйте ссылку в Happ из буфера обмена для нужного списка серверов (или откройте ссылку как deeplink). Профиль **RU-DIRECT-KAZAN** активируется для выбранного списка.
4. Переподключение Happ для применения — **только вручную, когда удобно пользователю**. Никаких действий с работающим VPN автоматически эта публикация не производит.

## Правила

- **DIRECT**: все домены из `ru-direct-extended.domains.txt` в категории `geosite:flint2-ru-direct`, встроенная категория `geosite:category-ru`, приватные и российские IP (`geoip:private`, `geoip:ru`).
- **PROXY раньше DIRECT**: сохранены исключения для Google/YouTube, OpenAI, Telegram, Discord и прочих международных сервисов, а также отдельные RU-домены и IP-сети из RoutingA Flint 2.
- Остальное **через VPN** (`GlobalProxy: true`). Приватные/локальные IP идут напрямую.
- `Happ_RU_Direct_Kazan_NL.json` — читаемый профиль. `geosite.dat` — компактная Xray-совместимая GEO-база с нужными исходными категориями и полным списком российских доменов. Это **не тот же формат**, что файл Subscription URL GL.iNet.

## Обновления

GitHub Actions `../.github/workflows/update-domains.yml` каждый день в 03:17 UTC собирает:
- общие списки для Flint 2 и RoutingA;
- `Happ_RU_Direct_Kazan_NL.json`;
- `Happ_Import_Link.txt`;
- `happ/geosite.dat`.

При недоступности источника или отсутствии нужных GEO-категорий задача завершается ошибкой и не публикует повреждённый новый набор. В репозитории сохраняется последний успешно сгенерированный набор.

**Важно о клиентах:** GitHub обновляется автоматически. Happ использует URL GEO-базы и по своей политике может обновлять геофайлы (документация указывает ограничение не чаще раза в неделю). Чтобы гарантированно применить новое содержание/новые правила, повторно импортируйте **актуальную строку** из `Happ_Import_Link.txt` с тем же именем профиля и переподключитесь сами. Нельзя обещать мгновенное автоматическое обновление правил во всех версиях Happ.

## Как добавить российский сайт

Вписать домен отдельной строкой в `../extra-domains.txt` и сохранить в GitHub. Все три набора — Flint 2, v2rayA RoutingA и Happ — обновятся общей GitHub Actions.

Инструкция Happ: https://www.happ.su/main/ru/dev-docs/routing

**Happ работает независимо от Flint 2:** эти ссылки ничего не меняют в роутере, на Windows или в работающих VPN-подключениях без вашего импорта.
