# Happ: RU DIRECT → KAZAN / NL

Профиль раздельной маршрутизации для **Happ на Android и Windows**, подготовлен 22.11.2026.

**Принцип:** российские сайты и IP — напрямую через местного интернет-провайдера; зарубежный трафик, в частности ChatGPT/YouTube/Google/Telegram, — через персональный VLESS в Казань. На Казани уже работает серверная маршрутизация, и только при необходимости трафик идёт дальше через Нидерланды.

## Получить профиль

- **Ссылка для импорта:** [Happ_Import_Link.txt](Happ_Import_Link.txt) (скопировать всё содержимое, начиная с `happ://routing/onadd/`, и открыть в Happ).
- **Конфигурация в JSON:** [Happ_RU_Direct_Kazan_NL.json](Happ_RU_Direct_Kazan_NL.json) (для просмотра и проверки в https://routing.happ.su).
- **Инструкция Happ:** https://www.happ.su/main/ru/dev-docs/routing
- **Исходный российский список роутера:** [ru-direct-extended.domains.txt](../ru-direct-extended.domains.txt) (справочно, не импортировать напрямую в Happ!).

## Установка

1. Установите Happ и импортируйте личную VLESS-ссылку Казани от администратора (НЕ из этого репозитория).
2. Откройте файл `Happ_Import_Link.txt`, скопируйте всю ссылку `happ://routing/onadd/...`. Импортируйте её в Happ с помощью ссылки или QR-кода, если его прислали отдельно.
3. Дождитесь загрузки GEO-файлов. В настройках маршрутизации выбранной подписки/списка серверов включите профиль **RU-DIRECT-KAZAN**.
4. Переподключите VPN (Reconnect): новая маршрутизация применяется после переподключения.
5. Проверьте российский и зарубежный сайты. При необходимости временно выключите маршрутизацию в Happ для диагностики и переподключитесь.

**Приоритет:** исключения PROXY обрабатываются перед DIRECT, затем неизвестные направления по умолчанию направляются в VPN. Профиль использует `geosite:category-ru` и `geoip:ru` с дополнительными доменами, поэтому **не является буквальной копией 1836 строк** из GitHub-списка Flint 2 и не обновляется из этого списка автоматически. Геофайлы управляются приложением Happ.

**Важно:** при использовании ограниченных JSON-подписок Happ может запрещать добавление отдельного пользовательского профиля маршрутизации. Для обычной персональной ссылки `vless://` эта оговорка обычно не относится. Не публикуйте и не пересылайте посторонним собственную клиентскую `vless://` ссылку или QR для входа на сервер.

Задача маршрутизации — снизить нагрузку и расход транзитного трафика казанского VPS. **Наличие ограничений тарифа или величина экономии не проверялись.**
